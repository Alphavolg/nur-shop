# Vercel ready Next.js storefront for نور شاپ

This repository contains a Persian beauty product storefront built for Vercel deployment.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Import this repository into Vercel.
2. Keep the default Next.js build settings.
3. Deploy.

This is a Vercel-compatible storefront, not the WordPress + WooCommerce pipeline from `Alphavolg/wp-site-factory`.
